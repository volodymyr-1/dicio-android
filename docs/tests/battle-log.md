результат записываем сюда. Обновляется после каждой итерации.

## Как снимать
```
adb shell run-as <package> cat files/diagnostics.log
```
`<package>` = `org.stypox.dicio.<ветка>` (debug-суффикс). logcat не пригоден (ADR-6).
