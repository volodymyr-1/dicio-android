# Протокол боевых прогонов (battle log)

Каждый боевой прогон: говорим фразы на планшете → снимаем diagnostics.log → разбираем →
результат записываем сюда. Обновляется после каждой итерации.

## Прогон 1 — 2026-09-10 (до роутера, сборка с диагностикой)
Полный цикл логируется: BOOT/WAKE/STT/ROUTER/SKILL/OUTPUT/TTS — наблюдаемость подтверждена.
Найдены и закрыты: ложные GREETING/NAME/SKILLS; «Можете повторить?» на будильник.
TTS — системный, качество плохое (пользователь: «ужасно») — отдельная задача.

## Как снимать
```
adb shell run-as <package> cat files/diagnostics.log
```
`<package>` = `org.stypox.dicio.<ветка>` (debug-суффикс). logcat не пригоден (ADR-6).
